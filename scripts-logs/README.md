# Scripts to perform Universal Cell Embedding
The shell scripts within this directory have been executed from the parent directory (the root directory of this repository). 
To perform a new embedding, do the following (note, these are performed on DCC):
1) Edit/modify one of these scripts and save it with a new name (keep the original)  
1) Move the new script to the parent directory.  
1) Activate the uce conda enviroment using: `conda activate uce`  
1) Execute the script using: `sbatch run-<script-name>.sh`
